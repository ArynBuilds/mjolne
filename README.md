# MJØLNE Roastery Co.

Brand-led e-commerce site for a specialty coffee roastery: story, brew guides,
product pages, a subscription configurator, cart and checkout, and customer
accounts for recurring bean delivery.

The brief that shaped it, from PRODUCT.md: the marketing surfaces are the primary
register - "the design IS the product" - and the utility surfaces (configurator,
account, checkout) hold the same editorial tone instead of drifting into generic
SaaS. DESIGN.md and DECISIONS.md carry the full design system and the calls made
along the way.

Built solo, 2026. Next.js, TypeScript, Tailwind.

Status: archived - no longer deployed.
